## IndexNow (Bing & Yandex)

The IndexNow verification key file lives in [`public/21354682e160bfc63a1e562fc58c16b9.txt`](public/21354682e160bfc63a1e562fc58c16b9.txt) and must be deployed live before submitting URLs.

- Preview the JSON payload locally without sending a network request:
  ```bash
  npm run indexnow -- --dry-run
  ```
- Submit all URLs matching `sitemap.xml` after deploying to production:
  ```bash
  npm run indexnow
  ```
- Submit only specific updated URLs:
  ```bash
  npm run indexnow -- /blog/how-to-download-skool-videos
  ```
